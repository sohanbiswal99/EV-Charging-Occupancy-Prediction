📌 Overview

With the rapid growth of Electric Vehicles, efficient charging infrastructure is becoming increasingly important.

This project uses Machine Learning to predict EV charging station occupancy, helping improve station utilization, availability, and overall user experience.

🔄 End-to-End Workflow

Data → Preprocessing → EDA → Feature Selection → Model Training → Evaluation → Deployment

🤖 Machine Learning Model

Algorithm: 🌳 Decision Tree Classifier
